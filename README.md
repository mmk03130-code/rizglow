# Rizglow™ — by RS Studio

Aesthetic theming app: curated wallpapers, matching icons, live widgets and
floating pets — realistic, premium, never kiddie.

**Phase 1:** app shell (splash, onboarding, 4 tabs, dark gallery style,
`UnlockManager` ads seam for rewarded-ad bundle unlocks).

Built with Kotlin + classic Android Views, zero external dependencies.
CI builds a debug APK on every push to `main` via GitHub Actions.
