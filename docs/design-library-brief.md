# Rizglow Design Library Brief (2026-10-10)

## Market landscape (top personalization apps, Play Store)
- **Themepack (YoloTech)** — 120M installs, 4.7★. The giant. 10,000+ widgets/icons/wallpapers, DIY icons, one-click apply. Themes: aesthetic, K-pop, anime, neon, sports, festival.
- **ThemeKit** — 62M. **iControl** — 41M. **Themie** — 19M. **Widget 2026** — 14M. **Widgeet** — 13M. **CutePop** (girly wallpapers) — 4.8M. **Glassify** — rising.
- Takeaway: winners all do **one-click full-theme packs** (wallpaper + icons + widgets together), live previews, and categories by aesthetic.

## Trending style families (Etsy/Lemon8, 2026)
1. **Coquette** — bows, lace, ribbons, cherries, balletcore, pink/black, vanilla tones
2. **Clean girl** — minimalist, neutral beige/cream, chic, subtle textures
3. **Y2K** — angel numbers, hearts, chrome, retro digital, frutiger aero
4. **Dark feminine** — black + pink/red, gothic florals
5. **Cottagecore/fairycore** — mushrooms, bears, cozy hand-drawn
6. **K-pop/anime/neon** — fandom-adjacent brights (careful: no trademarks)

## Naming conventions (what sells)
- Pattern: **[Mood/Place/Object] + [Aesthetic word]** — "Pink Lace Dreams", "Versailles Blush", "Frog Lily Pad", "Bear Cottage", "Sunrise Beach", "Gold Leaf"
- Two-word evocative names beat descriptive ones. Keep them trademark-free.

## Copyright guardrails (hard rules)
1. **Never** use trademarked names: no BTS, Pokemon, Dior, Chanel, Hello Kitty, Disney, anime titles, celebrity names. (Etsy sellers do "BTS Purple", "Miss Dior" — that's infringement risk we don't take.)
2. **Safe**: generic style words — coquette, Y2K, cottagecore, fairycore, clean girl, balletcore.
3. **Always generate our own art** — never scrape Pinterest/Google/IG images.
4. Mascots: our black cat is original — keep building around it, it's our differentiator.

## UX takeaways (ease of use)
1. **One-tap full-theme apply** — we have per-bundle Apply Theme; keep it front and center.
2. **Live previews** — wallpaper preview exists; next: home-screen mockup preview per bundle.
3. **Categories/filters** — tabs exist; consider style filters (Feminine / Dark / Minimal / Bold).
4. **First-run guidance** — step-by-step ("1. Pick a bundle 2. Apply 3. Add widgets") for new users.
5. **DIY touches** (later) — icon label fonts, widget text — Themepack's retention driver.
